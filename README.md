## 🌍 Proyecto Base de Datos - Turismo Perú 2026

## 📘 Descripción General
Este proyecto tiene como objetivo gestionar los datos del sistema Turismo Perú, integrando herramientas de desarrollo como Python, Flask, SQL Server, Git y Visual Studio Code.

## 🚀 Fases del Proyecto
- Fase de Configuración de Entorno
- Fase de Desarrollo (MVC, Conexión a BD, Procedimientos Almacenados)
- Fase de Documentación y Versionamiento

## 🧠 Competencias a Desarrollar
Maneja entornos de desarrollo con Visual Studio Code y entornos virtuales.
Utiliza Git Bash para versionar proyectos y gestionar ramas.
Aplica estructuras de Python (Flask) y bases de datos relacionales (SQL Server).

## 🗂️ Estructura del Proyecto
```bash
TurismoPeru_2026/
│
├── controllers/       # Controladores de la aplicación
├── database/          # Archivos de conexión a base de datos
├── models/            # Clases de Python (Persona, Cliente)
├── procedures/        # Scripts de procedimientos almacenados SQL
├── scripts/           # Scripts de automatización de carpetas
├── static/            # Archivos estáticos
├── templates/         # Plantillas HTML (index, clientes, insertar)
├── .env               # Variables de entorno y credenciales (Oculto)
├── .gitignore         # Archivos ignorados por Git
├── app.py             # Archivo principal de ejecución de Flask
├── config.py          # Configuración de entorno
└── requirements.txt   # Dependencias del proyecto
## 🧰 Requisitos
- Python 3.x
- pyodbc
- Flask
- python-dotenv
